Data Wrangling with pdxTrees

pdxTrees is a data package composed of information on inventoried trees in Portland, OR. There are two datasets that can be accessed with this package:

  • get_pdxTrees_parks(version = "2019") pulls in data on up to 25,534 trees from 174 Portland parks.

  • get_pdxTrees_parks(version = "2026") pulls in data on up to 25,734 trees from 316 Portland parks.

  • get_pdxTrees_streets(version = "2019") pulls in data on up to 218,602 trees located on Portland’s streets. A street tree is loosely defined as a tree generally in the public right-of-way, usually between the sidewalk and the street. *get_pdxTrees_streets(version = "2026) pulls in data on up to 252,180 trees located on Portland’s streets. A street tree is loosely defined as a tree generally in the public right-of-way, usually between the sidewalk and the street.

The street trees are categorized by one of the 95 Portland neighborhoods and the park trees are categorized by the public parks in which they grow.

Here are some examples of the different ways pdxTrees can be used in an educational setting to learn data visualization!

Creating a new variable with mutate() and case_when()

The following code creates an new variable with mutate, case_when, and the pdxTrees_parks data. It: * Removes three variables from the new subset data set using select * Creates a new variable that groups the carbon storage values int NA, Low, Moderate, and High * Shows you the first few rows of the new subset data set * Counts how many trees are in each category of carbon_group


# Pulling the data for Parks from the 2019 data set

pdxTrees_Parks <- get_pdxTrees_parks()

#create a subset data frame
Carbon_Parks <- pdxTrees_Parks %>%
    #get rid of extra variables
    select(-c("Collected_By", "Nuisance", "Functional_Type")) %>%
    #add a new variable that groups carbon storage value
    mutate(Carbon_Group = case_when(
        is.na(Carbon_Storage_value) ~ NA,
        Carbon_Storage_value <= 250 ~ "Low",
        between(Carbon_Storage_value, 250, 750) ~ "Moderate",
        Carbon_Storage_value > 750 ~ "High"))

Finding Summary Statistics and grouping

The following code finds summary statistics for each category of Condition before arranging it in ascending order with group_by, summarize, arrange, and the pdxTrees_parks data.


#create a subset data frame
Park_Stats <- Carbon_Parks %>%
  # group data by each category of condition
    group_by(Condition) %>%
  # find the mean DBH and tree height in each category and count how many trees per category
    summarize(mean_DBH = mean(DBH, na.rm = TRUE),
        mean_tree_height = mean(Tree_Height, na.rm = TRUE),
        trees = n()) %>%
  #arrange the data in ascending order by trees
    arrange(trees)

Changing the class of a variable and ordering the levels

The following code identifies the class and level of a variable and changes it with class, mutate, factor, levels, and the pdxTrees_parks data.


#show variable class 
class(Carbon_Parks$Condition)
#> [1] "character"
#show variable order
levels(Carbon_Parks$Condition)
#> NULL


#change to ordered and set the order
Carbon_Parks <- Carbon_Parks %>%
  mutate(Condition = factor(Condition,
      levels = c("Dead", "Poor", "Fair", "Good")))


#show new variable class 
class(Carbon_Parks$Condition)
#> [1] "factor"
#show new variable order
levels(Carbon_Parks$Condition)
#> [1] "Dead" "Poor" "Fair" "Good"

Are Nuisance trees commonly the inedible or edible trees?

The following code test if Nuisance trees commonly the inedible or edible trees with filter, count, and the pdxTrees_parks data.

  filter(Edible == c("No", "Yes", "Yes - fruit", "Yes - nuts"))

# filter nuisance to yes
